# Video Rental Advanced System App

## Functionalities implemented


1. ROLE:  


    CUSTOMER Video CRUD operations  
    Read Video, Rent 2 Videos, Return Videos  


    ADMIN: Video CRUD operations  
    Create Video, Read Video, Update Video, Delete Video, Rent 2 Videos, Return Videos   


2. Public endpoints (JWT)  
register, login


## How to execute the application

1. Create MySQL Database and configure properties

2. Run application
`./gradlew bootrun`
